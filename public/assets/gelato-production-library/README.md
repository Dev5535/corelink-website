# CoreLink Gelato Production Library

This directory contains **PRINT-READY** assets for Gelato production.
**DO NOT** modify these files. They are generated to specific dimensions and DPI settings.

## Structure
- **Apparel**: Hoodies, Tees, Onesies (Adult & Kids)
- **Tech Accessories**: Phone Cases, Laptop Skins, Desk Mats
- **Home Living**: Duvet Covers, Rugs
- **Bags & Lifestyle**: Backpacks

## Naming Convention
`CoreLink_[Category]_[SubCategory]_[Variant].png`

## Specifications
- **Apparel**: 4500x5400px @ 300 DPI (Chest Logo Placement)
- **Phone Cases**: 2000x4000px (Full Wrap)
- **Desk Mats**: 6000x3000px (Full Wrap + Logo)
- **Home**: Up to 6000x6000px

## Assets Used
- Master Nebula (Dark Blue/Purple)
- Soft Nebula (Kids/Pastel)
- Neon Angel Logo (Transparent)
